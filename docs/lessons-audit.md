A current enforcement path means the lesson names a concrete file found in the repository. NONE means no such path was confirmed from the record. A path alone does not prove complete enforcement.

Tier 1 means prevent by construction. Tier 2 means an unconditional fail-closed check at the named pipeline stage. Tier 3 means process or judgement: client intent, aesthetics and uncertain evidence have no reliable numeric surrogate. Each proposed proof needs a real or injected failure, a clean case that stays quiet, and a run on D2, D3 or the bedroom.
