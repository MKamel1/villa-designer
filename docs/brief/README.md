# Brief supporting material

Where Stage 0 (Intent) inputs live that are not the `brief.yaml` itself.

- **Taste board** — reference images. Drop them here and list them under
  `aesthetic.references` in `spec/villa-brief.yaml`. They are read for
  concrete attributes (palette, material, proportion, light quality),
  not adjectives.
- Interview notes, sketches, anything the brief was derived from.

The brief is filled by interview, not by handing the client a form.
