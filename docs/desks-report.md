## Shared fit module

[`archpipe.furniture_fit`](../src/archpipe/furniture_fit.py) now owns measured
bounds, declared source-unit conversion, contents retention, plan-factor
limits, and independent vertical arithmetic. Beds call it through their
existing APIs and retain mattress/berth/headboard, placement, cloth and C8
checks. C8 means the geometry-topology room review.

Plan width and depth factors must each be 0.5–2.0 after unit conversion;
larger divided by smaller minus one must not exceed 0.15 (15 percent), in
either axis order. All design distances are metres. This retains the client
rule from [beds-report.md](beds-report.md), rather than introducing an
ergonomic standard. Unit conversion requires an identified declaration;
missing evidence means the glTF metre convention, never a factor inferred
from a target. New furniture intake rejects an explicit empty unit record;
the bed adapter preserves its historical empty-record default.

`fit_furniture` measures retained converted faces. New contents contracts
require `item-only`, a review basis and explicit omissions of separately
named extras; fused extras refuse. Existing `bed-only` contracts also work.
The vertical factor derives from actual named desktop/seat geometry above
the retained item bottom and a `design` or `citation` source. Required
additional datums, such as chair-back height, use `height_constraints` and
must fit that same transform. No leg, seat or back is stretched separately.
The result reports overall height; fitting the footprint alone is not
acceptance. No new ergonomic height was invented for this stage.

The shared solver is intake arithmetic. Later desk/chair activation still
needs imported-transform verification, reviewed neutral and room previews,
all required heights and full room checks. The legacy renderer's chair
candidate selection still uses its existing product-size proxies and
`place_model` path; Stage 1 does not wire this new contract into activation
or certify those existing candidates. See the repeatable
[furniture workflow](ops/furniture-fit.md).
