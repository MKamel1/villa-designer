# Villa lighting - request to confirm luminaire availability

**To:** the lighting supplier  
**Attached:** `luminaire-schedule.xlsx` (the same table as `luminaire-schedule.pdf`)

## What we are asking

We have designed the lighting of a private villa and need to know which products you can supply in Egypt.
The attached schedule lists every luminaire type, how many we need, and the **performance each one must meet**.

We have **not fixed the products**. The product named in each row is only an example that shows the performance we
calculated with. Any common product of a similar performance is welcome.
Every row therefore reads: **"or approved equivalent - submit the IES/LDT file and the datasheet"**.

## What we ask you to do

1. For each row, answer one of: **available** (as the example), **equivalent** (tell us the product), or **not found**.
2. For each equivalent, send the product's **IES or LDT file** (the maker's photometric file) and its **datasheet (PDF)**.
3. Tell us, for each product, the lumens, colour temperature, CRI (and R9 if known), beam angle, IP rating, dimming
   protocol, cut-out or size and finish. Please do not send prices or lead times at this stage.
4. If a product is not available, say so; do not substitute silently.

## What must stay fixed

- Warm white **2700 K** (the night-light strips are 2200 K), **CRI 90 or higher**.
- Every fitting **dimmable**: **DALI-2** (or the on-board dimmer named in the row). No phase-cut dimmers.
- The **beam type** (a narrow spot must stay a narrow spot; a wide flood must stay wide).
- **IP rating** where the row asks for more than IP20 (bathrooms: IP44).
- Light output is flexible within the range in the row. A product with different output is acceptable if we can set
  its dimming level so the room still gets the right light with at least 20 % in reserve; we check that for you.

## What happens next

We check each proposal against its row (output, beam, colour, dimming, the real rooms). We reply per row with one of:

- **ACCEPT**: use it as it is.
- **ACCEPT WITH DIMMING CHANGE**: use it; only the commissioning dimming level changes. We tell you the new level.
- **REJECT**: with the reason (for example "beam too wide", "phase-cut only"). Then please propose another.

When the installer later gives us the exact list of what will be installed, we run the same check on that list, so
nothing is bought that does not work in the room.

Please reply to the sender of this note. A partial answer is fine: send what you have and we will iterate.
