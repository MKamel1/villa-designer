Exposure stops are base-two camera-gain units; one additional stop doubles gain. Display luminance is weighted red/green/blue pixel brightness between zero and one. Linear log-average luminance is measured before camera development, in renderer units, and is not illuminance. Lumens measure emitted light. QA means image quality assurance. A cohort is the complete authored view list sharing an exposure state. SHA-256 is a content hash. The fix requires a graphics device before expensive assembly unless `--cpu` explicitly requests diagnosis, and reports the configured device/backend/names beside each image. Tests freeze the empty inventory, refuse a renamed CPU-only sibling, and accept a graphics inventory, CUDA alternative and explicit CPU diagnostic. The runtime render log is retained separately as evidence that the selected graphics backend actually rendered. This correction changes execution admission and evidence, not design transport, lamps, camera or QA thresholds.
