# Discussion log — 2026-09-20 kickoff

Participants: mmbka (client/governance), Claude (design lead).

A record of what was decided, what was rejected and why, including the
course corrections. Kept honest deliberately: the wrong turns are more
useful to a later reader than a tidy narrative.

---

## Starting point

The brief was "help me build AutoCAD and preferably Revit for an apartment
or villa". Machine survey found AutoCAD 2026 (full, not LT) with a working
`accoreconsole.exe`, Python 3.14, Node 26, WSL Ubuntu — and **no Revit**.

## What was built first, and why it was set aside

A spec-driven 2D pipeline: `spec/apartment.yaml` → DXF → DWG → plotted
A3 PDF at a verified 1:50, entirely headless. Plus a design rule engine
(12 rules, Neufert-cited), a furniture catalogue with clearances, and a
web review sheet with a coordinate transform verified to 0.01 mm.

It worked, and it demonstrated the core idea: the rule engine independently
found a design fault the human-written review notes had missed (the living
room had no window at all). It also caught a fault in its own demo spec —
a window placed exactly where a partition landed.

It was set aside as the *authoring* path when the client chose BIM. The
rule engine, catalogue, viewer and transform all survive, because they
operate on the schema rather than on how the schema was produced.

## Decisions taken

| Decision | Record |
|---|---|
| Revit is the single source of truth | ADR-0001 |
| The text model is a generated extract, never authored | ADR-0002 |
| `ai-workstation` runs everything non-Autodesk | ADR-0003 |
| Lighting compliance is arithmetic; rendering is for feel | ADR-0004 |
| Education licence accepted, watermark acknowledged | ADR-0005 |
| Revit on the Windows PC; single-machine VM deferred | ADR-0006 |
| Own design method instead of RIBA | ADR-0007 |

Also settled: metric millimetres with ISO 13567-style layers; Neufert as
the dimensional base with no jurisdiction fixed yet; the AI leads and the
client governs, with an absolute client veto recorded as a waiver.

## Course corrections made by the client

Recorded because each one changed the direction materially.

1. **"I don't care about the findings of the example, I care to build a
   full reviewer/advisor."** The demo apartment was treated as the
   deliverable when it was only a test fixture.

2. **"The viewer is weak... I can't draw, highlight, communicate with the
   AI."** Correct. The review sheet pinned notes and nothing more. A
   compounding error: the live page was never republished, so the client
   spent the review period looking at a version already superseded. Cause:
   the agent held the republish to avoid changing the page mid-review, and
   did not say clearly enough that the improvements were invisible.

3. **"RIBA feels shallow and doesn't exactly fit a villa project."**
   Correct, and the agent should have flagged it rather than adopting it.
   RIBA is a procurement framework, silent on how to design, and forbids
   the iteration a house needs. Replaced — see ADR-0007.

4. **"Make the framework have inner loops."** Design does not run
   forwards. Thirteen named backward paths added (L1–L13) with four
   thrash-control mechanisms.

5. **"I want the AI leading and the client approving, reviewing, giving
   opinion, suggesting solutions, or vetoing."** Authority split made
   explicit in the PRD and the method.

## Options rejected

- **YAML generates the Revit model** — preserves determinism, but edits
  made inside Revit are destroyed on regeneration. Unworkable.
- **Bidirectional Revit/text sync** — two sources of truth.
- **IFC via IfcOpenShell as the BIM path** — free and Linux-native, but an
  imported IFC arrives in Revit as generic geometry, not native
  parametric elements. Real as a deliverable, not as a substitute.
- **Everything on Linux including Revit** — impossible; no Linux build and
  Wine is not viable for Autodesk products.
- **Build the Windows VM now** — hardware is capable and it was deferred,
  not dismissed (ADR-0006).
- **Autodesk Viewer / APS for client markup** — needs an Autodesk account
  and an upload, and its markup does not return as actionable data.
- **Revision cloud and region-select markup tools** — not chosen; ink,
  highlight, arrow/callout and measure were.
- **Pattern Language alone as the framework** — a catalogue, not a
  process: no sequencing, no gates.

## Technical findings worth keeping

- **accoreconsole traps** (all hit for real): an invalid answer to a
  keyword prompt blocks forever and ignores stdin EOF; the `-PLOT` prompt
  sequence differs between Model and a named layout; a **relative script
  path makes it exit 0 having done nothing**, which is indistinguishable
  from success; `SAVEAS` over an existing file prompts to overwrite and
  wedges.
- **Revit has no headless mode.** `pyrevit run` may provide command-line
  automation — unverified, and the automation story depends on it.
- **A published artifact declaring `db` is organisation-internal** and
  cannot be shared by public link. Relevant if an external client ever
  needs the review sheet.
- **Dashed linetypes plot solid** through the AutoCAD layout viewport; the
  same geometry renders dashed in the web sheet, so the fault is in the
  plot path. Unresolved.
