# ADR-0005 — Education licensing and watermarks

- **Status:** accepted
- **Date:** 2026-09-20

## Context

The available Autodesk licence is an education licence.

## Decision

Proceed on the education licence for this personal project, with the
limitation recorded rather than discovered later.

## Consequences

- **Output carries an education watermark**, and it propagates into files
  consumed downstream. Acceptable for a personal project; **disqualifying**
  for anything going to a client, a contractor or an authority.
- Autodesk's education terms are scoped to educational use. Designing
  one's own home sits outside that as written. Flagged once; the client's
  call, and the client has made it.
- If the project ever changes purpose, licensing must be revisited before
  any output is issued.
