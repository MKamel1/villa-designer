# L6c lessons (defect -> why it was missed -> guard)

| defect | why it was missed | guard now |
|---|---|---|
| ERCO IES files crashed `ies2rad` ("illegal source dimensions", "bad luminaire data"): byte-order mark and LM-63 negative (circular) opening dimensions. | Every file used so far (iGuzzini, generic) was written by a tool that avoids both; V10 reads the files in Python, which tolerates them, so the product passed V10 and still could not reach Radiance. | `radiance_safe_ies` on the text handed to Radiance (photometry untouched); `test_radiance_safe_ies_strips_bom_and_negative_opening` (fails on the raw ERCO file) and its negative (an ordinary file is unchanged). |
| A 56 deg wide-flood downlight kept in the parents' bedroom put 23 217 cd/m2 into the eye of a person lying on the bed (cap 3000). | The 732 lm 33 deg fitting it replaced never had that fitting in the 45 deg cone; a rebind changes angular reach, not only lumens. | LA4 (`test_la4_luminance_within_cap`) caught it on the first test run after the rebind; the kept fitting is the one by the entry. |
| The independent patch radiosity (8 x 8) agreed with Radiance within 6 % only for the old narrow distributions; for the ERCO wide floods it overstated three small rooms by 7-10 %. | The guard's tolerance was tuned to the products at the time (the same trap as "tune the parameter"): its resolution was never shown to be converged. | Patches 16 x 16 and bar 8 % (convergence shown: guest WC 236 -> 219 -> 215 lx Radiance); the converged value, not the coarse one, is the reference. |
| The substitution command first reported identical numbers for the design and the proposal (the lazy `Fixture.record` was evaluated after the patched product was restored). | A positive-only run (a REJECT on beam alone) looked plausible; the room table was not compared with the design column. | `test_stronger_product...` (drivers must move) and `test_a_weaker_product_is_rejected...`: a proposal with different lumens must change the plane values; placements are built eagerly inside the patch (`_by_fixture`). |
| `PEN-LIN` was a point source of 1200 lm in L6b (the design never set a length) although the docstring says it is sampled. | The check compared totals, not the shape; 3558 lm as a point source would have overstated the table near field. | `test_table_pendant_is_sampled_along_its_length` (8 points over 1.5 m x 7/8, flux = 2 x 1779 lm x driver). |
| Waiting loops matched themselves (`pgrep -f` of the pattern that is in the loop's own command line) and ran for the whole timeout. | Process lesson, not a design defect. | Wait on files (`[ -f result.json ]`), not on process names. |
