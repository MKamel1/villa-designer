# LP: luminaire products with public photometric data

Client decision 2026-11-21: nothing bought yet; prefer makers that publish photometry openly so every product can be
checked against the manufacturer's lab data. Data: `knowledge/lighting-products/candidates.json`
(files, sha256 and source per product; code `src/archpipe/luminaires/v10.py`, `lp_candidates.py`; tests `tests/luminaires/`).

## Bottom line

**No product reaches a full V10 pass for any design kind.** Every maker with the richest datasheets (ERCO, Zumtobel/Thorn,
Signify, Delta Light) either blocks automated download or serves files through JavaScript, and I did not circumvent that.
The 6 products obtained are all iGuzzini, whose product pages publish only Imax, flux, LOR and beam angle: no
lux-at-distance cone table, no UGR table, no datasheet PDF. Four things stand in V10 terms:

* **lumens-only** (file integrates, two independent ways, to the lumen figure in the manufacturer's own product name,
  worst error 0.4 %) for the five products that fill a kind;
* a **full pass** only for iGuzzini 451G (Sipario, 3000 K track spot, 1957.5 lm): Imax 5759 cd vs 5736.6 (0.4 %), beam
  34 deg vs 33.9 (0.4 %), flux 1957.5 lm vs 1956.7 (0.04 %). It matches no design kind (track mount, 3000 K, 1957 lm), so
  it is a reference for the method, not a recommendation.

## Why nothing else (observed 2026-11-21)

ERCO: HTTP 429 with a bot challenge. Thorn: 403. Signify: file API needs a person (robots.txt, per `signify.py`).
Zumtobel: LDT/IES buttons are JavaScript with no static URL. Delta Light: files generated by an API from JavaScript.
Astro: PDFs publish "Lamp Dependent" flux/CCT/CRI and no IES/LDT. Lumenpulse: IES zips are public (LCRS fixed-tilt
downloaded and listed) but the spec sheet has only nominal beam angles; North American 120-277 V product. Flos, Reggiani,
Wever & Ducre: not reached (wever-ducre.com did not connect). Full text in `candidates.json` `sourcing_log`.

## Next step that needs a person

Download from ERCO, Zumtobel, Delta Light and Signify in a browser, drop the LDT/IES and the datasheet PDF into
`assets/user/luminaires/inbox/<maker>/`, and enter the datasheet's lux/beam-diameter table as `v10.Point` rows
(`lux_axis`, `beam_diameter`) in `lp_candidates.PRODUCTS`; `v10.reproduce` already checks both routes (engine
`lightcalc.direct` and an independent reader) and the negative cases are tested. ERCO and Zumtobel datasheets carry
the illuminance cone tables this needs.

## Decisions

* A figure typed from memory is not published data: only the 451G page values I read today are entered as points.
* LSEVO file names: product URL was not recorded at import (2026-09-27); sidecar says so.
* "pass" requires a non-lumen published point; lumen agreement with the product name alone is `lumens-only`.
* Redistribution: files are public iGuzzini downloads for design use; their terms were not separately read.
