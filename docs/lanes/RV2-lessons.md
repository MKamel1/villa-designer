# RV2 lessons (defect, why it was missed, guard)

| id | defect | why it was missed | guard now |
|---|---|---|---|
| RV2-01 | `door-B-cinema-store-ramp` has `rotation_deg` 0 but its host wall runs along y; the plan code took the opening axis from the rotation, so the leaf and hinge were drawn on the wrong jamb (plan A-101, store door) | positive tests only counted tags and chains; nothing compared the drawn hinge with the authored `hinge_xy_mm` | `sheetqa.handing_violations` (drawn hinge within 150 mm of `hinge_xy_mm`, every hinged door has a swing); `_opening_frame` now follows the host wall; `sheetqa.opening_axis_findings` reports the model inconsistency (1 door) to the model lane. Test `test_hinge_check_catches_the_real_rotation_defect` reproduces the old behaviour and fails on it |
| RV2-02 | the old plans drew model +y up and labelled it north (D15) | the label was a constant; no test knew where the street is | `orient.to_client` (single rotation) plus `sheetqa.orientation_violations`: reads the PDF text positions of the tags and compares every room/door pair with the model (street higher, east to the right). Three wrong frames (old convention, mirrored, flipped) each trip it (>20 violations of ~480 pairs) |
| RV2-03 | the first section had no poche on slabs or walls: the scene shell is finish skins (1 mm layers), not closed solids, so a winding-number fill is empty between the skins | the probe used boxes; the real scene was only looked at after the first render | poche comes from the design-model solids (`modelcut`), lines from the scene; `test_model_cut_matches_known_dimensions` (slab -3.2..-3.0, stair opening, lowest tread at larger x) |
| RV2-04 | elevations first included the plot fence, the sister villa and neighbours: the scene shell is merged by material across the whole plot, so a per-mesh filter keeps them | per-mesh ids looked sufficient | `scene_slim` filters per FACE; `sheetqa.view_violations` compares the stroke extent in u with the model footprint on the same axis (a mirrored or over-wide view fails: 4 wrong before the fix, 0 after) |
| RV2-05 | legend text "R01"/"D01" was picked up as the first tag in the PDF read-back, giving 39 false orientation violations | the read-back takes the first matching word | legends use `Rnn`/`Dnn`/`Wnn`; the tag read-back would be wrong again if a legend reused real tags, so the test `test_correct_plan_has_zero_violations` runs on the real sheet |
