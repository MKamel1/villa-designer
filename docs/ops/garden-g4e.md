# G4e diagnostic appearance correction

Use the specified Linux Python with `PYTHONPATH=src`, `NO_COLOR=1` and
`OPENBLAS_NUM_THREADS=1` for bounded numerical work. Do not install packages,
commit, or write through `out/villa/round3` or `assets/user`.

Keep the workstation's actual 1b4f33b scene and linear image read-only. Freeze
actual plants, fixtures, sky and camera by value before editing. The current
fixture source, shield, aim, flux, spectrum and all design locations remain
unchanged. The plant palette continues to own the young envelope.

1. Reconstruct each species through `garden_g4e.clump`; both original shared
   entry points delegate to it. Resolve actual materials before previewing.
   Require `habit_findings` and the existing leaf-only soil-gap check.
2. Use `garden_g6_preview.py` on before/after assemblies with the previous
   receipt as `--reference-receipt`; inspect every instance. New geometry,
   material or identity invalidates the receipt. The 1.8 m figure and neutral
   staging remain identical; glossy leaves use an explicitly assumed material.
3. `garden_g4e_diagnose.py` performs four low-resolution, linear-only source
   isolations: combined, sky only, uplights only and sky with zero gravel
   albedo. The last is a diagnostic intervention, never an authored finish.
   Disable all luminous lens shaders in source isolation.
   Use production `configure_glass` in probes and neutral previews; classify
   surfaces behind transparent panes rather than treating the pane as foliage.
   Read the retained EXR and call the production villa QA context adapter for the historical
   display image. Do not alter exposure, white balance, sky or QA limits.
4. Search cameras against immutable scene geometry. Actual projection,
   first-hit visibility, foreground-fitting visibility, measured interior
   or open-sky standing domain, opening-frame central-third and lens clearance
   all apply. Search the
   adjacent room if a narrow court cannot hold the view. Captions state
   through-glazing/rear-basket limitations; never promise the seating face.
   Check existing views after a denser habit: fixed envelope is insufficient.
5. Neutral context disables all design emissive shaders. Record any neutral
   softbox in `neutral_preview_fill`, identically for before/after; it is
   diagnostic lighting and must never be exported as design lighting.
   Preview and independently review the relocated v42 and affected v37.
6. The authoritative comparison lists the ten changed plant meshes, exact
   unchanged other faces/lights and props compared by identity, the new
   material and two camera
   changes. `v41-north-garden-evening` is a recorded alias for v42; numeric
   view prefixes are unique in the scene contract.
7. Run focused landscape/render-standard/render-view/garden/fixture/material
   regressions and portable verification, then portable verification with a
   newly empty HOME. Keep exit statuses and measured report current. A
   diagnostic probe or neutral preview does not establish new presentation QA.
